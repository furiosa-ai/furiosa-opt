# Tools

These tools support installation and the development process for kernel work.

- [Kernel Optimizer](./kernel-optimizer.md): The cargo subcommand that drives the toolchain: backend selection, automatic kernel builds, and direct kernel compilation.
- [Language Server](./language-server.md): Installation and configuration of `furiosa-rust-analyzer-proxy` for IDE integration.
- [Schedule Viewer](./schedule-viewer.md): An interactive viewer for inspecting schedule JSON files.
