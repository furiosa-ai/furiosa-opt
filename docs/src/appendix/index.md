# Appendix

The following sections contain reference material for development tools that complement the Furiosa IR Optimizer.

- [`cargo-furiosa-opt`](./cargo-furiosa-opt.md): The cargo subcommand that drives the toolchain — backend selection, automatic kernel builds, and direct compiler mode.
- [Language Server](./language-server.md): Installation and configuration of `furiosa-rust-analyzer-proxy` for IDE integration.
- [Schedule Viewer](./schedule-viewer.md): An interactive viewer for inspecting schedule JSON files.
