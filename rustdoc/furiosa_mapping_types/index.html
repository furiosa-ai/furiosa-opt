Structs§

Broadcast
Broadcast expression: SIZE iterations of a stride-0 (don’t-care) axis. Broadcast<1> is the identity (the unit written m![1]).
Ident
Axis identifiers.
Index
A buffer cell’s read: the per-axis contributions on a live cell, or the PaddingKind it lands on otherwise (Bottom for an out-of-bounds / over-modulo read with no covering pad). A non-live cell’s kind is decided by the MAJOR (outermost) factor that hits a pad first.
Modulo
Modulo expression that represents modulo SIZE elements.
Padding
Add padding to increase an expression’s size.
Pair
Pair expression of two expressions.
RSortedMap
A FFI-safe ordered map backed by a sorted RVec<Tuple2<K, V>>.
Resize
Truncate expression to SIZE elements.
SequencerConfig
Successful result of sequencing: the matched entries that tile the stream, keyed by their stream-side stride (the buffer position they tile, innermost-first).
SequencerEntry
One entry of a SequencerConfig: the matched sub-layout, which input memory it reads/writes (memory_index into the memory vector passed to the matcher), and the buffer stride within that memory. memory_stride == 0 marks a broadcast (no memory access). Single-memory callers use memory_index == 0.
Stride
Stride expression that represents one for every SIZE elements.
Symbol
Symbol expression that represents a single axis.
Term
inner / stride % modulo, the key of an Index.
