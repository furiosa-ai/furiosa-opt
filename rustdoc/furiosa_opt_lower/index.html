Furiosa-opt lowering engines.

Two kinds of function live here. The lowering algorithms (config_transpose, config_fetch, …) are thin safe wrappers over the prebuilt, hidden furiosa-opt-lower-impl static library: the resolved results cross the extern "C-unwind" boundary as [furiosa_opt_lower_types] StableAbi values, and each wrapper converts back to a plain Result. The engine verifications (the config_* in [verify]) are published in full: they state the DSL contract in pure furiosa_mapping terms, with no hidden algorithm. Both the frontend (furiosa-opt-std) and the IR backend (tu-ops / npu-visa-translate) call all of these.

Structs§

DivideTerm
One matched axis of a divide, FMapping-free: the engines read its strides, live size, and idents without ever naming the factor algebra it came from. dividend_stride / divisor_stride are the cumulative-product strides on each side; resize is the live cell count; idents are the symbols the matched term carries.
FactorLeaf
One factor leaf of a mapping, FMapping-free: a named axis (ident) or an untagged run (a composite the matcher didn’t flatten, or a padding over-read), with its live cell count. The IR fetch projection reads these innermost-first instead of walking the hidden factor list.
RelaxedDivision
The relaxed view of a divide (partial overlap allowed): the matched axes plus what is left over on each side as a plain Mapping, and the contiguous reachable tail the DMA-layout check reads. All FMapping-free — residues cross as Mapping, never as factors.
StreamSequencerConfig
The sequencer config for a whole stream: the (time, packet) descriptors an engine resolves, the fetch read or the commit write, each a [SequencerConfig] keyed by stream stride. Common to both.
TransposeConfig
Resolved transpose-engine hardware parameters (all counts in elements).

config_cast
The input packet must be exactly one flit; the output packet must be the input recast to out_bits and repadded to one flit. in_bits/out_bits are the input/output element bit-widths.
config_collect
Pads the input packet to a flit-aligned boundary, then splits at the flit: the inner flit must be packet2, and the outer portion folded onto time must be time2.
config_commit
Synthesize the commit write descriptors, or the CommitError.
config_commit_trim
The output packet must be one of the hardware commit widths and a resize (trimming) of the input.
config_contract_lane
contract_lane performs no reduction, so the outer portion of OutTime must equal Time, the output packet must be one flit, and the axes inner to the outermost reduce must fit the accumulator.
config_contract_packet
The input packet is one or two flits, the output packet is a power-of-two within the accumulator width, and the output is a prefix-contraction of the input.
config_contract_time
OutTime must divide Time exactly (reduced axes are the quotient); retained axes keep their order and edge-to-edge padding.
config_divide_exact
