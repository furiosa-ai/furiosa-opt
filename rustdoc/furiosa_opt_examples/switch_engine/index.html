Switch Engine examples: each #[device] fn lowers a SwitchConfig::CustomBroadcast and is checked bit-exact (VISA vs LIR) in npu-visa-test.

Axis scoping: Chip/Cluster and the (B, V) time/packet axes below are shared by every example. Every other axis is declared in its own axes! block directly above the single example that uses it, so each block’s domain is exactly that example.
