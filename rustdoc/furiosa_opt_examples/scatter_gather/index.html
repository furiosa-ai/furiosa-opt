Module scatter_gather

Expand description

Scatter/gather test kernels.

scatter_minimal scatters K = 512 keys into a C = 612 cache (sparse: C > K); the non-power-of-2, larger-than-K cache stresses non-aligned scatter coverage.

gather_minimal gathers G = 512 rows from the K-row table. Its gather count G is separate from the scatter cache C so the values partition G / 2 = 256 equals num_slices (the sparse C / 2 = 306 would round up past it and fail to lower). gather_unaligned covers a non-power-of-2 count (U = 768, 3 rows/slice) that still meets the 256-slice constraint.

gather_paged_kv gathers over a 4-D DRAM pool whose gather-key label NBlocks is reused in the gathered output. That reused key is what the visa->LIR indirect-key relabeling isolates by subtracting the index’s own labels.
