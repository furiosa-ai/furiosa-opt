Trait ExtendBuffers 

Source 
pub trait ExtendBuffers<A> {
    // Required method
    fn extend<I: IntoIterator<Item = A>>(&mut self, iter: I);
}
Expand description

Extend-shaped trait for Vec<Buffer>, narrowed to this crate’s needs.

Has the identical signature to core::iter::Extend<A>, same &mut self receiver, same IntoIterator<Item = A> parameter, same extend method name.

Required Methods§

Source

fn extend<I: IntoIterator<Item = A>>(&mut self, iter: I)

Extends self with one DMA buffer per leaf tensor produced by iter.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
