Expand description

Valid zero-point-subtraction widenings for fetch_zero_point_sub.

Subtracting the zero point widens an integer to its contraction-engine staging type, which holds the (value - zero_point) range: i4 -> i5 and i8 -> i9 (see i5/i9 for why the extra bit is needed). Only these pairs have an impl, so an invalid widening (e.g. i8 -> i5) is a compile error. This is the only way to produce an i5/i9; fetch_cast cannot.

Required Associated Constants§

Source

const ZERO_POINT_RANGE: RangeInclusive<i32>

Valid zero-point range: the source integer type’s own range (i4: [-8, 7], i8: [-128, 127]). A zero point inside it keeps every value - zero_point residual within Out, so the caller checks zero_point once (data-independent) instead of each widened element.

Required Methods§

Source

fn zero_point_sub(self, zero_point: i32) -> Out

Subtracts zero_point (already range-checked against ZERO_POINT_RANGE) and widens self to Out.
