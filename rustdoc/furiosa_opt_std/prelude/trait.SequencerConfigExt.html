fn coalesce(self) -> Self

Coalesces entries that sit back-to-back in the memory buffer into one, to minimize the sequencer entry count. Result entries are keyed by cumulative-product stream stride, so adjacent entries are always stream-contiguous; the merge condition is memory-contiguity alone (inner.memory_stride * inner.size == outer.memory_stride). The merged entry keeps the inner’s key and memory stride, with the run paired into one mapping.

Apply this PER descriptor (e.g. packet and time separately), never across, or it would coalesce two entries that must stay distinct.
