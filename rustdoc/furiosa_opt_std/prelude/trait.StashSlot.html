Expand description

Occupancy of the stash slot at compile time. D ties an occupied slot’s scalar to the pipeline’s, so a stash read is checked against the current D. See the module docs for the full lifecycle.

Provided Methods§

Source

fn clone_tensor_as<TargetMapping: M>(&self) -> Option<Tensor<D, TargetMapping>>

Clones the slot’s tensor (transposed to TargetMapping); None for the empty states (Fresh / Spent). Only Occupied overrides the default.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
