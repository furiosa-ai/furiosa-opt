Trait Plain 

Source 
pub trait Plain: Sealed { }
Expand description

An operand that leaves the stash slot alone (everything but Stash). Only exists to exclude Stash from the identity StashTransition blanket below – Rust has no negative bounds, so a catch-all impl<T> plus the Stash override would collide. Sealed: a new operand type must opt in with impl Plain (plus the paired impl sealed::Sealed) or an explicit StashTransition, so forgetting the transition is a compile error rather than silent identity.
